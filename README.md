One emoji that stands for an AI agent: the octopus, 🐙.

## Why the octopus?

An AI agent is smart and does many things at once — juggling tools, tasks,
and conversations in parallel. The octopus captures that in a single glyph:
a clever creature with eight arms, all working at the same time. It reads
instantly at small size, says something specific about how the agent works,
and is far from the obvious robot or smiley.

## How to run

```sh
python3 main.py
```

This writes exactly one character, 🐙, to `/output/entry.txt` — no trailing
newline, no extra text. Set `OUTPUT_DIR` to write somewhere else:

```sh
OUTPUT_DIR=/tmp/out python3 main.py
```
